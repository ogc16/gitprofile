# Caleb Ngeno's Portfolio

A personal portfolio website built with [GitProfile](https://github.com/arifszn/gitprofile), powered by Vite, React, TypeScript, and daisyUI.

## Tech Stack

- **Vite 7** — Build tool
- **React 18** — UI framework
- **TypeScript** — Type safety
- **Tailwind CSS 4** — Utility-first CSS
- **daisyUI 5** — UI components
- **Vite PWA** — Progressive Web App support

## Getting Started

```bash
pnpm install
pnpm run dev
```

Open [http://localhost:5173/gitprofile/](http://localhost:5173/gitprofile/).

## Build

```bash
pnpm run build
```

Output goes to `dist/`.

## Deploy

```bash
pnpm run deploy
```

Deploys the `docs/` folder to GitHub Pages.

## Configuration

Edit `gitprofile.config.ts` to customize:

- GitHub username and projects
- Social links
- Skills, experience, education
- Theme and layout
- SEO metadata
